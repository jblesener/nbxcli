## nbxcli create

Create a NetBox resource

```
nbxcli create RESOURCE [flags]
```

### Options

```
      --data string      JSON object or @path to a JSON file
  -h, --help             help for create
  -o, --output string    output format: table or json (default "table")
      --profile string   saved NetBox profile to use
```
