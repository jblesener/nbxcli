## nbxcli auth token rotate

Replace a saved v2 API token and revoke the previous token

```
nbxcli auth token rotate [flags]
```

### Options

```
  -h, --help             help for rotate
      --profile string   saved NetBox profile to use
  -y, --yes              confirm rotation without prompting
```
