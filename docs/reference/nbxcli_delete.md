## nbxcli delete

Delete a NetBox resource

```
nbxcli delete RESOURCE ID [flags]
```

### Options

```
  -h, --help             help for delete
      --profile string   saved NetBox profile to use
  -y, --yes              confirm deletion without prompting
```
