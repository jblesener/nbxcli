## nbxcli get

List or retrieve a NetBox resource

```
nbxcli get RESOURCE [ID] [flags]
```

### Options

```
      --filter stringArray   NetBox resource filter in key=value form (repeatable)
  -h, --help                 help for get
      --limit int            maximum number of records to return (default 100)
  -o, --output string        output format: table or json (default "table")
      --profile string       saved NetBox profile to use
      --search string        free-text resource search
```
