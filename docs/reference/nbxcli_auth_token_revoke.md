## nbxcli auth token revoke

Revoke a saved v2 API token and remove its profile

```
nbxcli auth token revoke [flags]
```

### Options

```
  -h, --help             help for revoke
      --profile string   saved NetBox profile to use
  -y, --yes              confirm revocation without prompting
```
